# auto-periodic-switch

Arduino UNO R3 とマイクロサーボ SG92R で、ある装置の押し釦スイッチを約1時間おき（約59.3分周期）に自動で押下するツールの制御コード。

関連記事：[定期的にある装置の押し釦スイッチを自動で押下してくれるツールのコストダウン版製作記](https://note.com/komaajx/n/n8c602f891f0e)（note）

## 動作

- 使用開始直後は、対象装置の電源が切れている前提で、電源を入れるために1回だけ押下する
- 以降の周期では、入っている電源をいったん切って入れ直すため、2回押下する
- 待機中はディープスリープ（8秒 × 445回 ≒ 約59.3分）で消費電力を抑える
- スリープ中の誤回転対策として、眠る前にサーボ制御を切り離し（detach）、信号ピンを LOW に固定する。起床時は現在の角度を先に指示してから制御を再開する
- 起動時に、直前のリセット要因を基板上の LED の点滅回数で知らせる診断付き

## 部品

- UNO R3 ボード（互換ボード）
- アクリルケース（UNO R3 用）
- マイクロサーボ SG92R
- ジャンパーワイヤー

部品代の合計は約 2,618 円（送料込み。USB Type-B ケーブルと電源を除く）。

## 配線

- サーボの信号線（橙）：D9
- サーボの電源（赤）：5V
- サーボの GND（黒）：GND

## 使い方

1. Arduino IDE で `AutoPeriodicSwitch/AutoPeriodicSwitch.ino` を開く
2. ライブラリマネージャから **Low-Power** をインストールする（Servo は標準ライブラリ）
3. ボード（Arduino Uno）とポートを選んで書き込む
4. サーボの取り付け状態に合わせて、コード先頭の「設定項目」にある `startAngle`（待機角度）と `targetAngleMove`（押下角度）を微調整する
